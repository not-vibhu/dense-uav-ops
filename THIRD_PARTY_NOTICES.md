## Studied, not used

- **NASA ICAROUS** (revision `4a3bcf443e516c713c775bd6d32b8184d57c4ea2`): its module structure informed the v0.4 design notes (archived). No ICAROUS code is used or redistributed.
- **OpenUTM Flight Blender, InterUSS DSS and monitoring, OpenDroneID**: referenced in the archived v0.4 architecture documents as integration targets. No code is used.

## Standards

ASTM F3411 (Remote ID), F3548 (USS interoperability) and F3442 (detect-and-avoid performance), RTCA DO-365, and related standards are cited by title and public scope only. No normative text is reproduced. Nothing in this repository claims conformance with any standard.

## Data

All evidence under `experiments/` is synthetic simulation output generated by this project's code. It contains no flight, Remote ID, ADS-B or personal data.
